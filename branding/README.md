# MyCrobo brand assets

The versioned assets in this directory and `apps/client/assets` contain the approved product identity. The v1 lockup set was supplied on 2026-08-26; the v2 app icon was cleaned from the approved MyCrobo mark supplied on 2026-10-09.

- `mycrobo-logo-master-v1.png`: supplied master artwork, preserved without modification.
- `mycrobo-mark-v1.png`: transparent square product mark for app surfaces.
- `mycrobo-lockup-v1.png`: transparent horizontal product lockup for headers and startup.
- `mycrobo-app-v2.ico`: Windows multi-resolution icon (16–256 px), derived from the approved MyCrobo mark.
- `mycrobo-installer-sidebar-v1.png`: master installer artwork.
- `mycrobo-installer-sidebar-164x314-v1.png`: NSIS-compatible installer sidebar export.

Do not stretch, recolor, rotate, outline, or add effects to the mark. Use the lockup on warm white or very light neutral surfaces; maintain clear space equal to at least the dot diameter around it.
